## 8. Короткие тезисы для защиты

- RMSE выбран как стандартная метрика magnitude error, но дополнительно проверена MAE на тех же forecast-level артефактах.
- Прирост Directional Accuracy у метамодели положителен в среднем на всех горизонтах; для h=1 и h=5 он устойчив при clustered bootstrap, для h=20 вывод слабее.
- Распределение выигрышей показывает, что эффект не универсален для каждого ряда: есть инструменты и folds без улучшения или с ухудшением.
- Парные сравнения metamodel, best fixed и oracle построены на одних и тех же test meta-observations.
- Held-out instruments, rolling-origin folds и сохранённые split seeds снижают риск переобучения и позволяют проводить clustered / hierarchical bootstrap.
- RMSE чувствителен к экстремальным ошибкам; проверка MAE и trimming показывает, что вывод о силе baseline-моделей не исчезает.
- Прямой train-test gap для всех forecasting candidates не сохранён, поэтому диагностика переобучения chaos-inspired моделей ограничена без повторного benchmark.
- Fold-aware train-only признаки позволяют проверить стабильность характеристик рядов во времени; часть признаков стабильна, часть требует осторожной интерпретации.
